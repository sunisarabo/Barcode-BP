# ส่ง Scan Log เข้า Google Sheet (Google Apps Script)

เว็บแอปส่ง log บัตรที่สแกนไปที่ **Google Apps Script (GAS) Web App** แล้ว GAS
เขียนลง Google Sheet โดยจัด:

- **แท็บตามปี-เดือน** เช่น `2026-03` (1 แท็บต่อเดือน)
- ในแต่ละแท็บ **จัดกลุ่มตามเที่ยวบิน** (เรียงเที่ยวบิน → เวลา) มีคอลัมน์ **ประตู** ด้วย
- แท็บ **`สรุป`** รวมยอด ตามปี/เดือน/เที่ยวบิน (ผ่าน / ซ้ำ / ผิด)
- **กันข้อมูลซ้ำ** ด้วย `id` ของแต่ละรายการ (ส่งซ้ำได้ ไม่เพิ่มซ้ำ)
- **รองรับหลายประตูพร้อมกัน** (เช่น 40 ไฟลท์) — ทุกเครื่องส่งเข้า Sheet เดียวกันได้

## ตั้งค่าครั้งเดียว

1. เปิด https://script.google.com → **New project**
2. ลบโค้ดเดิม แล้ววางเนื้อหาจากไฟล์ [`Code.gs`](Code.gs) ทั้งหมด
3. กด **Deploy → New deployment**
   - เลือกชนิด (เฟือง ⚙️) = **Web app**
   - **Execute as**: `Me` (บัญชีคุณ)
   - **Who has access**: `Anyone`  ← สำคัญ เพื่อให้เว็บแอปส่งข้อมูลเข้าได้
   - กด **Deploy** แล้วอนุญาตสิทธิ์ (authorize) ครั้งแรก
4. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
5. เปิดเว็บแอป Boarding Pass Reader → ช่อง "วาง Google Apps Script Web App URL"
   วาง URL นั้น → กดปุ่ม **📤 Sheet**
6. Google Sheet ชื่อ **"Boarding Scan Log"** จะถูกสร้างอัตโนมัติในไดรฟ์ของคุณ
   (ครั้งแรก) — เปิดดูข้อมูลได้เลย
7. **(แนะนำ) เปิดแท็บสรุปอัตโนมัติ**: ในตัวแก้ไข Apps Script เลือกฟังก์ชัน
   `setup` แล้วกด **Run** หนึ่งครั้ง — จะตั้ง trigger ให้ rebuild แท็บ `สรุป`
   ทุก 5 นาที (แยกจากตอนเขียนข้อมูล เพื่อให้รับหลายเครื่องพร้อมกันได้เร็ว)
   · จะรีเฟรชเองก็ได้จากเมนู **Scan Log → รีเฟรชสรุป** ในตัว Sheet

## หมายเหตุ

- เว็บส่งแบบ `no-cors` (GAS ไม่ส่ง CORS header) — ส่งได้แต่หน้าเว็บอ่านผลกลับไม่ได้
  ปุ่มจะขึ้น "✅ ส่งแล้ว" เมื่อส่งสำเร็จ ให้ไปตรวจข้อมูลใน Google Sheet
- ส่งทั้ง log ทุกครั้ง แต่ GAS จะข้ามรายการที่ `id` เคยมีแล้ว จึงส่งซ้ำได้ปลอดภัย
- อยากได้ Sheet ที่มีอยู่แล้ว (ไม่สร้างใหม่): ไปที่ **Project Settings → Script
  Properties** เพิ่มคีย์ `SS_ID` = ไอดีของ Google Sheet ที่ต้องการ
- แก้โค้ดแล้วต้อง **Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New
  version** เพื่อให้ URL เดิมใช้โค้ดใหม่

## คอลัมน์ในแต่ละแท็บเดือน

| วันที่บิน | เวลาสแกน | เที่ยวบิน | ประตู | ผู้โดยสาร | ที่นั่ง | Seq | สถานะ | id |
|-----------|----------|-----------|-------|-----------|---------|-----|-------|-----|

สถานะ: `ผ่าน` / `บันทึก` / `ซ้ำ` / `ผิดเที่ยวบิน` / `ผิดวัน`

## ใช้หลายประตูพร้อมกัน (เช่น 40 ไฟลท์)

- แต่ละประตูเปิดเว็บแอปบนเครื่อง/แท็บของตัวเอง ตั้ง **ชื่อประตู** + **เที่ยวบิน**
  ของประตูนั้น แล้วชี้ไปที่ **URL เดียวกัน**
- เปิด **"ส่งเข้า Sheet อัตโนมัติ"** ที่แต่ละเครื่อง — ระบบรวมรายการยิงเป็นชุดทุก
  ~15 วิ (ไม่ยิงทุกครั้งที่สแกน) ช่วยลดการชนกันเมื่อหลายเครื่องส่งพร้อมกัน
- ฝั่ง GAS ใช้ `LockService` ทำให้เขียนทีละคำขอไม่ทับกัน + กันซ้ำด้วย `id`
- คอลัมน์ **ประตู** ทำให้แยกได้ว่าแต่ละรายการมาจากประตูไหน; แท็บ **สรุป** ยังรวม
  ยอดตามเที่ยวบินให้เห็นภาพรวมทั้ง 40 ไฟลท์
